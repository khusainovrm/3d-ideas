# Rostelecom logo asset

`rostelecom-horizontal.png` is an optimized 1800 px-wide copy of the official
horizontal RGB logo published by Rostelecom on its corporate identity page:

- Source page: https://www.company.rt.ru/about/identity/
- Original file: https://www.company.rt.ru/about/identity/files/RGB_RT_logo-horizontal_main_ru.png

The image proportions and artwork are unchanged. The local copy is downscaled
only to reduce browser decode memory while it is sampled as a particle mask.
