# Туманность hero из cloud.webp

Источник — `assets/cloud.webp`. Offline-скрипт `scripts/generateHeroCloud.mjs`
поворачивает изображение на 90° против часовой стрелки через sharp и сохраняет
яркостное поле 960×540 в `heroCloudData.generated.ts`.

Пересоздание после замены референса:

```sh
npm run generate:ribbon-cloud
```

`heroCloud.ts` строит равномерное покрытие с небольшим случайным смещением
вершин, двулинейно считывает яркость поля и задаёт прозрачность каждой точки.
Мягкие перекрывающиеся частицы воспроизводят непрерывную дымку; дополнительная
нелинейная экспозиция усиливает светлые узлы. Изображение не выводится отдельным
слоем или текстурой. Дрейф и глубина минимальны, чтобы сохранять форму референса.

- `PLANE_WIDTH` в `heroCloud.ts` — ширина в локальных координатах; пропорции 16:9 сохраняются.
- `exposure` — яркость пыли и узлов.
- `PARTICLE_COUNTS` в `scene.ts` — 140 / 240 / 360 тысяч исходных точек для low / medium / high.
- Диаметр частиц зависит от количества точек и размера экрана, чтобы при смене качества не появлялись разрывы покрытия.
- `nebulaRemainingPercent` в `navigation.ts` — остаточная яркость после сборки фигур.

Появление по-прежнему идёт случайным плавным fade без изменения масштаба.
Фигуры используют ту же геометрию; для фона сохраняются копии их исходных точек.
Старый `PARTICLE_CLOUD_PROMPT.md` описывает прежний процедурный генератор и
больше не является описанием действующего алгоритма.
