# Сферы выбора поворота

Общий переключатель: `RIBBON_ROAD_FEATURES.roadChoices` в `route.ts` (по умолчанию `true`).
В дебаге: **Feature toggles → Сферы поворота дороги**.

Группа из шести сфер (по три с каждой стороны) располагается возле точки дороги, соответствующей середине каждой DOM-секции.
Позиции учитывают перестановку секций через CSS `order`, их высоту и переход от hero к дороге.
Сферы видны вблизи шарика, имеют ядро около 20 CSS px и мягкое свечение.
Небольшой стабильный разброс по горизонтали и вертикали делает их похожими на пасхалки
рядом с дорогой. Верхняя и нижняя точки сохраняют своё положение относительно центральной.
Настройки применяются сразу; углы меняют в том числе уже выбранные повороты.
Дебаг-панель открывается через `#debug` в адресе страницы.

- До проезда группы все шесть сфер активны: тёплый цвет, увеличение при наведении.
- Центральная сфера слева/справа плавно поворачивает весь оставшийся путь влево/вправо.
  Верхняя с любой стороны поворачивает путь вверх, нижняя — вниз относительно экрана.
  Горизонтальный угол по умолчанию 25°, вертикальные — по 20°.
  До точки выбора дорога не меняется. После неё угол плавно нарастает на участке
  `turnLength`, затем весь хвост маршрута сохраняет полный поворот .
  Это вращение в 3D вокруг точки выбора, а не локальное смещение, возвращающееся к исходной дороге.
  Последовательные повороты складываются в порядке прохождения дороги.
  Геометрия дороги, шарик, камера, портал и следующие группы сфер следуют изменённому пути.
- После клика все шесть сфер группы блокируются, включая повторный проезд в обе стороны.
- Когда шарик находится за группой, все сферы блеклые и не реагируют на наведение/клик.
  Если выбор не делался, при возврате перед группой её можно выбрать.
- Выбор хранится отдельно для каждого маршрута в рамках текущей сцены.
  Кнопка «Сбросить» очищает выбор всех маршрутов; перезагрузка страницы также сбрасывает его.
- Выключение фичи скрывает сферы и отключает повороты, но не забывает сделанный выбор.

## Настройки

`ROAD_CHOICES` в `roadChoices.ts`; основные параметры доступны в папке дебага
**Сферы поворота дороги**:

| Параметр | Назначение |
| --- | --- |
| `sections` | Показывать ли группу в каждой конкретной секции |
| `diameter` | Диаметр ядра сферы в CSS px, без ореола |
| `turnAngle`, `upAngle`, `downAngle` | Углы горизонтального поворота, подъёма и спуска в градусах |
| `turnDuration` | Время анимации поворота в секундах |
| `turnLength` | Длина плавного входа в поворот после точки выбора, в нормализованном прогрессе дороги |
| `sideGap` | Дополнительный отступ сфер от половины ширины дороги |
| `verticalGap` | Расстояние между центральной и верхней/нижней сферами |
| `scatter`, `scatterSeed` | Сила и вариант стабильного случайного разброса; 0 отключает разброс |
| `opacity`, `inactiveOpacity` | Яркость доступных и заблокированных сфер |
| `hoverScale` | Увеличение при наведении |
| `visibilityDistance`, `visibilityWindow` | Дальность появления и окно видимости по прогрессу дороги |
| `activeColor`, `inactiveColor` | Цвет доступных и заблокированных сфер |

При `prefers-reduced-motion` поворот применяется без анимации.
Поворот не меняет параметризацию исходного маршрута, поэтому шарик не перескакивает
на другой участок из-за пересчёта длины кривой.

## Предпросмотр при наведении

При наведении на доступную сферу тонкая линия прокладывается от шарика по будущему
маршруту. Геометрия рассчитывается той же кривой и осью поворота, что и при клике,
без изменения самой дороги. При уходе курсора или выборе линия плавно исчезает;
при наведении на другую сферу прокладывание начинается заново. Заблокированные
сферы не показывают предпросмотр. При смене дороги, сбросе и отключении фичи линия
сразу скрывается; `prefers-reduced-motion` отключает анимацию.

В **Сферы поворота дороги → Предпросмотр маршрута** (`#debug`) доступны:

- включение, цвет, непрозрачность и толщина в экранных пикселях;
- время появления, исчезновения и продолжительность прокладывания;
- длина показываемого маршрута в нормализованном прогрессе (1 — весь оставшийся путь);
- сплошная или пунктирная форма, длина штрихов и промежутков в единицах сцены.

Настройки: `ROAD_CHOICE_PREVIEW` в `roadChoicePreview.ts`. Одна линия из 128 сегментов,
один вызов отрисовки, переиспользуемые буферы. Геометрия пересчитывается только при
изменении маршрута, положения шарика или направления поворота. Прокладывание
обновляет видимое число сегментов и положение кончика; неподвижная полностью
показанная линия не загружает геометрию заново. Пунктир и сплошная линия используют
один шейдер. Дополнительные текстуры, свечение и постобработка не требуются.
