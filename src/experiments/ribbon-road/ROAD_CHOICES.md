# Сферы выбора поворота

Общий переключатель: `RIBBON_ROAD_FEATURES.roadChoices` в `route.ts` (по умолчанию `true`).
В дебаге: **Feature toggles → Сферы поворота дороги**.

Пара сфер располагается возле точки дороги, соответствующей середине каждой DOM-секции.
Позиции учитывают перестановку секций через CSS `order`, их высоту и переход от hero к дороге.
Сферы видны вблизи шарика, имеют ядро около 20 CSS px и мягкое свечение.

- До проезда пары обе сферы активны: тёплый цвет, увеличение при наведении.
- Клик плавно поворачивает весь оставшийся путь в экранном направлении выбранной сферы.
  До точки выбора дорога не меняется. После неё угол плавно нарастает на участке
  `turnLength`, затем весь хвост маршрута сохраняет полный поворот (по умолчанию 25°).
  Это вращение в 3D вокруг точки выбора, а не локальное смещение, возвращающееся к исходной дороге.
  Последовательные повороты складываются в порядке прохождения дороги.
  Геометрия дороги, шарик, камера, портал и следующие пары сфер следуют изменённому пути.
- После клика обе сферы пары блокируются, включая повторный проезд в обе стороны.
- Когда шарик находится за парой, обе сферы блеклые и не реагируют на наведение/клик.
  Если выбор не делался, при возврате перед парой её можно выбрать.
- Выбор хранится отдельно для каждого маршрута в рамках текущей сцены.
  Кнопка «Сбросить» очищает выбор всех маршрутов; перезагрузка страницы также сбрасывает его.
- Выключение фичи скрывает сферы и отключает повороты, но не забывает сделанный выбор.

## Настройки

`ROAD_CHOICES` в `roadChoices.ts`; основные параметры доступны в папке дебага
**Сферы поворота дороги**:

| Параметр | Назначение |
| --- | --- |
| `sections` | Показывать ли пару в каждой конкретной секции |
| `diameter` | Диаметр ядра сферы в CSS px, без ореола |
| `turnAngle` | Угол поворота оставшегося пути в градусах |
| `turnDuration` | Время анимации поворота в секундах |
| `turnLength` | Длина плавного входа в поворот после точки выбора, в нормализованном прогрессе дороги |
| `sideGap` | Дополнительный отступ сфер от половины ширины дороги |
| `activeColor`, `inactiveColor` | Цвет доступных и заблокированных сфер |

При `prefers-reduced-motion` поворот применяется без анимации.
Поворот не меняет параметризацию исходного маршрута, поэтому шарик не перескакивает
на другой участок из-за пересчёта длины кривой.
